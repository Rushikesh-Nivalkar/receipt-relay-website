Download ReceiptRelay for Android

ReceiptRelay is free and runs on Android phones in Australia. Each release is published on GitHub with its checksum.

Open the latest release

Install the app

  1. Open the latest release on your phone and download the file ending in .apk.
  2. Compare its SHA-256 checksum with the one printed in the release notes.
  3. Open the file. Android asks once to allow installs from your browser.
  4. Open ReceiptRelay and scan your first receipt.

The first release is being built now. Until it is published, the link shows the release page with no files on it. A Google Play listing comes later.
